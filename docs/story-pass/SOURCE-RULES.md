# Story-image production rules (founder-locked 2026-10-31)

1. The 20 approved images in this folder are canonical. Do not regenerate or replace them without a founder ruling.
2. Quality is judged at the slot's real display size, not by a blanket "full-width" rule. Before generating, confirm the slot's maximum rendered CSS width; the file must be at least 2x that width.
3. A 2x2 grid (each tile ~832 px wide) is allowed only for slots rendering at ≤ 416 CSS px (e.g. the ZBC 4-column step timeline). Hero and full-width slots need a single full-size render (~1600 px wide).
4. Palette: ZBM = amber on near-black. Z Best Clips = coral on near-black. Never swap.
5. Never in an image: invented branding (including AI-made Z Best Media wordmarks), real logos or app icons, car/device badges, visible faces (pure silhouettes and hands only), fabricated metrics or numbers, readable gibberish text.
6. No claims in the image that the page copy doesn't make (e.g. "Auto Publish" vs "Every Submission Reviewed"). Prefer wordless images; the page text names the steps.
7. Vary composition: no more "monitor + desk lamp + black mug + sunset skyline" scenes; no handwritten checklist props.
8. Every image gets visual QA at 4x zoom on screens, cars, devices, hands and faces before upload, with a REVIEW.md row. Small badges or stray text may be removed by local inpaint (logged); faces, real logos and wrong-story images go back for an edit or regen.
9. Approval of artwork is not launch readiness. Launch still needs builder integration, responsive and accessibility checks, CI gates, and the founder's release decision.
